# Smart Image Renamer

一个 Chrome 扩展程序，用于自动重命名下载的图片文件并支持静默下载。

## 功能特性

- **智能重命名**: 根据域名和正则表达式自动重命名图片文件
- **静默下载**: 无需弹出保存对话框，直接下载到指定位置
- **灵活配置**: 为不同网站设置不同的重命名规则
- **自定义路径**: 可设置默认下载子目录

## 安装方法

1. 将所有文件放在一个文件夹中
2. 打开 Chrome 浏览器，访问 `chrome://extensions`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"，选择上述文件夹

## 使用说明

1. 安装扩展后，点击浏览器右上角的扩展图标，选择"选项"进入设置页面
2. 配置下载路径和重命名规则
3. **重要**: 在 Chrome 设置中关闭"下载前询问每个文件的保存位置"以实现静默下载
4. 访问包含图片的网站，下载图片时会自动应用重命名规则

## 规则配置说明

- **域名**: 指定规则适用的网站域名
- **匹配模式**: 使用正则表达式匹配原始文件名
- **替换格式**: 指定重命名后的文件名格式，可使用 $1, $2 等捕获组

### 示例
- 域名: `unsplash.com`
- 匹配模式: `unsplash_(.*)`
- 替换格式: `wallpaper_$1`

这会将 `unsplash_a1b2c3.jpg` 重命名为 `wallpaper_a1b2c3.jpg`

## 技术实现

- 使用 Manifest V3 规范
- 利用 `chrome.downloads.onDeterminingFilename` API 拦截下载
- 通过 `chrome.storage` API 存储用户配置
- 采用 Service Worker 架构实现后台功能
